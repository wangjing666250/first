# Pillar UI

一个面向中后台场景的 Vue 3 组件库，强调工程可维护性和组件高复用。

## 特性

- Vue 3 + TypeScript
- Monorepo 工程化
- 按需加载
- Vitest 单测
- VitePress 在线文档与示例
- CI 门禁与版本发布流程

## 当前组件

- 基础：Button、Input、Switch
- 表单：Select、Checkbox、Radio、AutoComplete、Upload
- 反馈：Message、Modal
- 数据：Table

## 快速开始

```bash
pnpm install
pnpm -w run dev
```

更多内容请查看 [快速开始](/guide/quickstart)。
